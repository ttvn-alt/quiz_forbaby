# 🩺 Nursing & Law Quiz Examination Portal

ระบบแบบทดสอบและคลังข้อสอบพยาบาล (วิชา Microbiology และ กฎหมายทั่วไปและการพยาบาล) สกัดข้อสอบคุณภาพสูงจากเอกสาร PDF กฎหมายและข้อบังคับสภาการพยาบาล

## 🌟 ฟีเจอร์เด่น (Key Features)

- 🦠 **วิชา Microbiology (จุลชีววิทยาประยุกต์คลินิก)**: ข้อสอบ 40 ข้อ ครอบคลุมแบคทีเรีย ไวรัส เชื้อรา ยาปฏิชีวนะ วัคซีน การควบคุมการติดเชื้อ และจุลชีววิทยาคลินิก
- ⚖️ **วิชา กฎหมายทั่วไปและการพยาบาล (General & Nursing Law)**: ข้อสอบ 40 ข้อ สกัดจาก PDF กฎหมายแพ่ง-อาญา, พ.ร.บ. วิชาชีพการพยาบาลฯ 2528/2540, พ.ร.บ. สุขภาพแห่งชาติ ม.12 (Living Will) / ม.7 (ความลับผู้ป่วย), พ.ร.บ. หลักประกันสุขภาพฯ ม.41 และ พ.ร.บ. โรคติดต่อ 2558
- 🎲 **ระบบสุ่มข้อสอบและสุ่มช้อยส์ (Randomization)**: สามารถเลือกสุ่มลำดับข้อสอบ สุ่มช้อยส์คำตอบ และเลือกจำนวนข้อสอบ (10 ข้อ, 20 ข้อ หรือทั้งหมด)
- 📖 **สรุปกฎหมายสำคัญ (Legal Cheat Sheet Modal)**: อ่านสรุปหัวใจสำคัญของกฎหมายก่อนทำข้อสอบ
- 🎨 **Modern Glassmorphic Design**: ดีไซน์สวยงาม ทันสมัย รองรับ Responsive บนมือถือ แท็บเล็ต และคอมพิวเตอร์
